# Implementação do Sistema de Clínica Médica

## Sobre o Projeto

Este projeto consiste na implementação de um **Sistema de Clínica Médica**, desenvolvido em **JavaScript** utilizando os conceitos de **Programação Orientada a Objetos (POO)**.

O objetivo é desenvolver um sistema para representar e organizar as principais entidades e funcionalidades de uma clínica médica.

## Conceitos de POO Utilizados

O projeto utiliza os principais conceitos da Programação Orientada a Objetos, como:

- Classes
- Objetos
- Atributos
- Métodos
- Construtores
- Encapsulamento
- Relacionamento entre classes

# Organização das Sprints

## Sprint 1 - Planejamento

### Objetivo

Definir o projeto e organizar a equipe.

### Atividades

- Divisão dos papéis da equipe;
- Definição dos objetivos do sistema;
- Levantamento das funcionalidades;
- Criação das primeiras tarefas;
- Planejamento do desenvolvimento.

---

## Sprint 2 - Desenvolvimento

### Objetivo

Implementar as principais funcionalidades do sistema.

### Atividades

- Implementação das classes;
- Criação dos atributos e métodos;
- Aplicação dos conceitos de POO;
- Desenvolvimento das funcionalidades;
- Integração entre as classes.

---

## Sprint 3 - Testes e Melhorias

### Objetivo

Corrigir problemas e melhorar o funcionamento do sistema.

### Atividades

- Testes das funcionalidades;
- Identificação de erros;
- Correção de bugs;
- Melhorias no código;
- Verificação da integração entre as classes.

---

## Sprint 4 - Finalização

### Objetivo

Preparar o projeto para a entrega.

### Atividades

- Testes finais;
- Revisão do código;
- Organização dos arquivos;
- Finalização da documentação;
- Preparação para a apresentação e entrega.

---

## Objetivo Final

Ao final do projeto, espera-se obter um **Sistema de Clínica Médica funcional**, desenvolvido em JavaScript e utilizando os princípios da Programação Orientada a Objetos.
